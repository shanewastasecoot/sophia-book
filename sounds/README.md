# Sound files

Drop a recorded sound here named after the sound it replaces, e.g. `boing.mp3` (a phone recording saved as `.m4a` works too).
The book plays the file instead of its built-in sound the next time a page that uses it opens. Sounds without a file keep the built-in version.
The book evens out loudness by itself, and turns everything down in bedtime mode. Keep each sound short (about 1 to 3 seconds).

Book 1: boing, swish, hum, rumble, burp, roar, chomp, stomp, toot, la, boom, pop, squeak, tweet, ding, honk

Mermaid City: splash, glub, twinkle, whoosh, boop, clank, squish, giggle, snort, bloop, blink, hoohoo, click, pickup, gate-open

The Gate Song notes (ocarina-pink, ocarina-blue, ocarina-gold) stay built in, so the tune is always exactly in pitch.
