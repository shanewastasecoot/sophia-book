# sophia-book

**Princess Sophia and the Noisy Shadow Demon**: a silly, sparkly picture book that Daddy has to read exactly the way it's written.

It's a single web page (`index.html`) with drawn illustrations, tap-to-play sound words, and big arrows to turn pages. To read it, open `index.html` in any browser, or turn on GitHub Pages for this repo (Settings → Pages → deploy from the `main` branch).
